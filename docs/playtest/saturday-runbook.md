# Суббота, 10.10: памятка ведущего

Адрес: **https://knowish.party**. Запасной: **https://quiz.ykhtskvch.workers.dev** (тот же сайт, та же игра).

## Накануне (пятница вечером)

- [ ] Генеральная репетиция прошла, правки задеплоены. После этого — **ничего не деплоить до игры**.
- [ ] Очистить production-аналитику после всех тестов, чтобы в субботней статистике были только настоящие игры:
      `cd apps/worker && npx wrangler d1 execute quiz-analytics --env production --remote --command "DELETE FROM question_stats; DELETE FROM answer_option_stats; DELETE FROM game_sessions; DELETE FROM session_feedback;"`
- [ ] Перед игрой не открывать вопросы в инструменте проверки (иначе они будут «знакомыми»).

## Перед началом (за 10 минут)

1. Общий экран — ТВ или ноутбук. Открыть **knowish.party**, выбрать язык игры, нажать «Создать игру».
   - Адрес экрана с `#t=…` в конце — это ключ экрана. Вкладку не закрывать; перезагрузка (F5) безопасна.
   - Яркость и масштаб: вопрос должен читаться с дивана. При необходимости — масштаб браузера.
2. **Первым** со своего телефона заходишь ты — первый вошедший становится ведущим (пауза, пропуск, «Закончить», «Сыграть ещё»).
3. Остальные сканируют QR с экрана (или вводят код на knowish.party). Каждый проходит короткий онбординг на своём телефоне.
4. Когда у всех «Готов» — «Начать» на телефоне ведущего. Игра — 20 вопросов, правила очков видны в лобби.

## Во время игры

- **Ошибка в вопросе** («так не бывает», «два правильных») — «Пропустить» на телефоне ведущего. Запомнить номер вопроса — после игры найти его в `npm run content:review`.
- **Перерыв** — «Пауза»; таймер замирает, после «Продолжить» оставшееся время восстанавливается.
- **Закончить раньше** — «Закончить», затем «Точно закончить?» в течение 3 секунд. Итоги считаются по сыгранным вопросам.

## Если что-то сломалось

| Что | Что делать |
|---|---|
| Экран завис / пишет «Переподключение…» дольше 10 секунд | Обновить страницу экрана (F5). Ключ в адресе — игра продолжится с того же места. |
| Телефон игрока отвалился, заблокировался | Открыть ссылку снова **в том же браузере** — игрок вернётся в комнату со своими очками. |
| Пропал телефон ведущего | С того же телефона и браузера — вернётся ведущим. Если телефона нет совсем: текущая игра доиграет сама, для новой — создать новую комнату. |
| Новый игрок пришёл посреди игры | Пусть заходит по QR — включится со следующего вопроса. |
| Сайт не открывается | Запасной адрес **quiz.ykhtskvch.workers.dev**. |
| Что-то странное и непонятное | Создать новую комнату — это 30 секунд. Время и что произошло — записать: логи — Cloudflare → Workers → `quiz` → Logs. |

## После игры

- Попросить всех заполнить короткую анкету на телефоне (главное — «Хочется сыграть ещё?»); оценка вопросов — по желанию.
- Записать впечатления по [чек-листу наблюдателя](observer-checklist.md), особенно спонтанное «давай ещё».
- Отчёт: `npm run analytics -- --production`.
- После субботы (решение L-D2): выключить черновики на production — `"ALLOW_DRAFTS": "false"` в `env.production` в `apps/worker/wrangler.jsonc`, затем `npm run deploy:production`.
