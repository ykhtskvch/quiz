# Плейтест: чек-лист наблюдателя

Цель M6 — 3–5 живых игр, чтобы проверить гипотезу продукта (каждый получает свой Hero Moment, после игры хочется сыграть ещё) и откалибровать движок. Аналитика в D1 говорит, *что* произошло; наблюдатель записывает, *почему*. Этот листок — то, что аналитика не видит.

Наблюдатель не играет и не подсказывает. Если игрока что-то сбило с толку — записать, а не объяснять (кроме полного блокера, см. «Когда вмешиваться»).

## До игры

- [ ] Сайт задеплоен, после деплоя прошла минута (новая версия раскатывается не мгновенно). Игра на **production (knowish.party)** — для генеральных репетиций и тестов можно staging.
- [ ] Аналитика очищена от тестовых игр (smoke и пробные игры тоже пишут в D1). Очищать перед первой настоящей игрой, дальше — не трогать:
      production: `cd apps/worker && npx wrangler d1 execute quiz-analytics --env production --remote --command "DELETE FROM question_stats; DELETE FROM answer_option_stats; DELETE FROM game_sessions; DELETE FROM session_feedback;"`
      staging: то же с `quiz-analytics-staging --env staging`.
- [ ] Во время серии игр smoke не запускать.
- [ ] Экран: ноутбук или телевизор, который видно всем; звук не нужен.
- [ ] Устройства игроков: записать модели и браузеры (iPhone/Safari, Android/Chrome…) — без имён, по буквам A–J (до 10 игроков).
- [ ] Wi-Fi: все в одной сети? (Все за одним IP — так и задумано; лимит запросов это учитывает.)
- [ ] Игрокам сказали: это тест, данные анонимные, наблюдатель записывает реакции, а не людей. Согласие получено.
- [ ] Записать: дата, время старта, язык комнаты, число игроков, состав (возраст, кто откуда — грубо, без имён).

## Онбординг (с момента, когда открыли ссылку)

| Что смотреть | Запись |
|---|---|
| Время от QR до «Готов» у каждого (A–J) | |
| Понимают ли разницу «что интересно» и «насколько знаешь» (шаги 2 и 3) | |
| Понятно ли ведущему, что «Start» нажимать ему; понятно ли остальным, что ждать | |

| Были ли темы, которые хотели выбрать, но не нашли | |
| Реакция на вопросы о культуре / происхождении (неловкость? пропустили?) | |
| Кто-то подглядывал или обсуждал ответы соседа | |

## Во время игры — по вопросам

Номер вопроса виден на экране. Записывать только то, что заметно; пустая строка — тоже информация.

| № | Реакция (смех, «о-о!», стон, тишина, спор) | Hero Moment? (кто, A–J) | Проблема с текстом (неоднозначно, ошибка, «нечестно») | Время (не успели / ждали) |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| … | | | | |

**Hero Moment** = один или двое ответили верно, остальные нет, и это *заметили*: «откуда ты знаешь?!», аплодисменты, человек объясняет остальным. Это главное, ради чего тест.

Отдельно отметить:

- [ ] Вопросы, которые вызвали обсуждение после reveal (хороший знак — даже если почти никто не ответил).
- [ ] Вопросы, на которые кто-то сказал «это нечестно» или «так не говорят» — сразу в очередь на правку.
- [ ] Ощущение темпа: в середине игры кто-то скучает, смотрит в другой телефон?
- [ ] Были ли игроки, которым за всю игру не досталось ни одного «своего» вопроса? (Спросить в конце, не во время.)
- [ ] Технические сбои: «переподключение…», задержки, телефон заблокировался, кто-то вылетел и вернулся. Время и устройство.
- [ ] **👍/👎 на разборе:** ставят ли (примерно сколько человек на вопрос)? Не утыкаются ли в телефоны в момент, когда комната обсуждает ответ? Если мешает — записать, кнопки легко убрать.
- [ ] **«А вы знали?»** (вторая половина разбора): читают ли, комментируют ли вслух — или ждут следующий вопрос?
- [ ] **Смешанная компания:** «мосты» (вопросы о постсоветском, понятные британцам) — объясняли ли друг другу, было ли британцам интересно, а не «это для них»?

## Когда вмешиваться

Только если игра встала: экран не обновляется больше 10 секунд, игрок не может вернуться в комнату, кнопки хоста не работают. Записать что было, что нажали, сколько времени заняло. Перезагрузка экрана (F5) безопасна — токен в адресе.

## После игры

- [ ] Дать всем заполнить анкету на телефоне **до** обсуждения (иначе ответы подстраиваются под громких).
- [ ] Записать время конца; кто нажал «Закончить» и почему, если досрочно.
- [ ] Спонтанно предложили сыграть ещё? Это сильнее любой анкеты — записать дословно.
- [ ] 3 коротких вопроса вслух (ответы — без имён):
  1. Какой вопрос запомнился? Почему?
  2. Был момент, когда ты знал(а) то, чего не знали другие?
  3. Что бы поменял(а)?

## Сопоставление с аналитикой

После серии игр:

```bash
npm run analytics -- --production   # или --staging для тестовых игр
```

| Аналитика | Наблюдение | Что делать |
|---|---|---|
| Точность по игре (цель 50–70 %) | Скучали / радовались | Симулятор оценивает точность по модели, которую никто не калибровал; реальная цифра отсюда — по ней правим `difficulty` у вопросов и веса движка |
| «Hero-удачи»: игрок, на которого движок нацелил вопрос, ответил верно, а большинство — нет | Записанные Hero Moments | Если proxy есть, а моментов не заметили — вопрос слишком тихий; если наоборот — proxy надо уточнить |
| Вопросы с «👎» и высоким skip | «Нечестно», «не так» | Править текст или снимать вопрос |
| «Хочется ещё» | Спонтанное «давай ещё» | Главная гипотеза |
| Темп «медленно / быстро» | Скука в середине | Таймеры в `packages/shared/src/config.ts` |

Номера вопросов в записях наблюдателя совпадают с порядком в игре; по тексту вопрос находится в `npm run content:review`.
