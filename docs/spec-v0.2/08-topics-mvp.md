# 08 — Taxonomy & Content Plan для MVP v0.1

> Новый документ по D-04. Язык банка — русский (C-009). Список — предложение Claude; правится свободно.

## 1. Принципы отбора тем

- **Покрыть все возрастные группы**, а не только 30–45 лет: у подростков должны быть свои Hero-темы.
- **Смешать высокую и низкую Dignity** примерно поровну.
- **Постсоветский слой — сильная сторона MVP**: ему отдано больше всего тем уровня A.
- **Тем меньше, чем хочется**: лучше 35 тем с достаточным числом вопросов, чем 80 тем по 3 вопроса. Без контента тема не попадает в onboarding.

## 2. Объём

| Уровень | Тем | Вопросов на тему | Итого |
|---|---|---|---|
| **A** — ядро, нужен для Hero | 15 | 15 | 225 |
| **B** — расширение | 20 | 8 | 160 |
| Wildcard / shared (без привязки к теме или GLOBAL easy–medium) | — | — | ~100 |
| **Всего** | 35 | | **~485** |

Порядок производства: сначала все A + 60 wildcard (≈ 285 вопросов, хватит на первый playtest), потом B.

Внутри темы — разброс сложности (≈ 3 easy / 6 medium / 4 hard / 2 specialist для A).

## 4. Карточки культурного бэкграунда (шаг D-01)

«С какой культурой ты вырос(ла)?» — multi-select, можно пропустить:

- Постсоветское пространство → `POST_SOVIET`
- Великобритания → `UK`
- США → `US`
- Европа → `EUROPE`
- Азия → `ASIA`
- Другое / не хочу указывать → без контекста

**Следствие правила непереводимости (BR-127):** в русской комнате вопросы с `culture_specificity = LOCAL` для UK / US не появятся — они существуют только на английском. Русскоязычный игрок, выросший в UK, получает «свои» вопросы только из GLOBAL / REGIONAL / bridge-вопросов на русском. Для MVP это нормально; полноценный UK-слой появится с EPIC 36.

## 5. Отложено (рекомендация)

| Тема | Почему не в MVP |
|---|---|
| Современная политика (после 2000) | Высокий риск конфликта в компании, быстро устаревает; противоречит правилу «без спорных edge cases» для opening и общему тону |
| Текущие военные конфликты | То же, плюс этические риски |
| Религия | Чувствительная тема, мало «удовольствия от ответа» |
| True crime | Требует аккуратной подачи при 13–17; можно вернуть позже в non-explicit форме |
| British TV, US pop culture как отдельные темы | Пока нет EN-комнат; см. EPIC 36 |

## 6. Риски покрытия

- **13–17 лет:** у них 6 тем уровня B (nature, music-now, internet-now, videogames, fandoms, cartoons) и ни одной уровня A, кроме мультфильмов. Если в playtest будут подростки, стоит поднять 1–2 темы до уровня A.
- **55+:** опора — ussr-everyday, soviet-cinema, ussr-history, russian-literature. Покрытие достаточное.
- **Устаревание:** internet-now и music-now быстро устаревают; ставить `time_sensitive = true` и проверять раз в квартал.
